Bikin Agent AI Sendiri, Tanpa Coding

Isi form, klik Buat Agent, lalu salin ke ChatGPT atau Gemini. AI-nya bakal kerja kayak agent: bikin rencana, nanya dulu, riset dari dokumenmu, bikin draf, ngecek diri sendiri, lalu nunggu persetujuanmu.

    5. Alat yang boleh dipakai

    Bedanya agent sama chatbot: agent milih sendiri kapan pakai alat. Centang alat yang boleh dia pakai.

    6. Tampilan app-mu (buat v0)

    Dipakai kalau kamu bikin app sendiri lewat v0.

    Bikin App-ku

    Satu klik, kamu dapat link app agent sendiri: ada diagram alur, kolom API key Gemini, dan agent-nya kerja beneran. Gratis, tanpa akun.

    Buka app
    Mau punya repo + domain sendiri? (Deploy versi kamu)
    1. Klik Deploy ke Vercel. Login pakai GitHub, beri nama repo, klik Create.
    2. Di GitHub, buka file agent.config.js di repo barumu, klik ikon pensil.
    3. Hapus isinya, tempel teks dari tombol di bawah, klik Commit changes.
    4. Tunggu sekitar 1 menit, Vercel otomatis update. Buka domain vercel.app-mu.
    Prompt agent kamu
    
  
    
  
    
    Cara bikin app-mu pakai v0
    
      
      
    1. Klik Salin di tab Prompt app (v0).
      2. 
      
    2. Buka v0.app, login (bisa pakai akun Google/GitHub), tempel prompt-nya, kirim.
      3. 
      
    3. Tunggu v0 selesai bikin app. Coba di Preview: tempel API key Gemini dari AI Studio, upload dokumen, klik Jalankan Agent.
      4. 
      
    4. Ada error? Ketik ke v0: "Ada error: (tempel pesan errornya), tolong perbaiki".
      5. 
      
    5. Klik Publish. Kamu dapat link app agent-mu sendiri, siap dipamerkan pas Show & Tell.
      6. 
    
    
    
    Akun gratis v0 dibatasi sekitar 7 pesan per hari, jadi prompt ini dibuat lengkap biar jadi dalam 1 kali kirim. Gemini API wajib 18+.
    
  
    
  
    
    Cara pakainya
    
      
      
    1. Klik Salin.
      2. 
      
    2. Buka ChatGPT atau Gemini, buat chat baru, tempel (Ctrl+V), kirim.
      3. 
      
    3. Upload dokumen sumbermu (PDF/Word), atau tempel isinya. Belum punya? Pakai dokumen latihan di bawah.
      4. 
      
    4. Jawab pertanyaannya: ketik Lanjut, lalu di akhir Setuju atau Revisi: ...

    Coba jebak agent-mu
    
    Agent yang bertanggung jawab nggak gampang dijebak. Kirim salah satu pesan ini di tengah obrolan, lalu lihat reaksinya.
    
    
      
  
      
  
      
    Simpan jadi agent permanen (Gem / GPT)
    
      Biar nggak copy-paste terus: simpan prompt-nya jadi agent yang punya nama dan link sendiri.
      
    Gemini Gems
    
        
      
      1. Buka gemini.google.com/gems, klik New Gem.
        2. 
      
      2. Isi nama sesuai nama agent-mu, tempel prompt di kolom Instructions.
        3. 
      
      3. Upload dokumen sumber di bagian Knowledge, lalu Save.
        4. 
      
      4. Buka Gem-nya dan ketik "Mulai". Agent-mu siap dipakai lagi kapan pun.
        5. 
    
      
    ChatGPT (Custom GPT)
    
        
      
      1. Buka chatgpt.com/gpts/editor, pilih tab Configure.
        2. 
      
      2. Tempel prompt di Instructions, upload dokumen di Knowledge, nyalakan alat yang kamu centang (Web Search, Image Generation).
        3. 
      
      3. Klik Create. Biasanya butuh akun ChatGPT berbayar untuk membuat GPT.
        4. 
    
      
  
      

      

      


      
  
      
  Mode lanjutan
  
      Jalankan agent-mu beneran di sini
      
  
      Pakai API key Gemini gratis punyamu sendiri. Di sini kamu bisa lihat agent-nya kerja: bikin rencana, milih alat sendiri, ngecek drafnya pakai aturan mainmu, lalu memperbaiki sendiri sebelum minta persetujuan.
      
  
        
    
      • Wajib 18 tahun ke atas (aturan Google untuk Gemini API). Belum 18? Pakai mode salin di atas.

        • 
    
      • Key cuma dipakai di browser-mu dan langsung dikirim ke Google. Hapus key-nya di AI Studio setelah workshop.
